# h264only

This userscript blocks support for any video compression standard besides H.264.
It's originally intended to be used on YouTube but should also work on any other
website that uses Web APIs to query client's capabilities.

To install the userscript, visit any of the userscript links below. The
userscript extension you use should suggest installation automatically. If that
didn't happen, install the script manually.

Userscript links:

- [Codeberg](https://codeberg.org/paveloom-o/h264only/raw/branch/main/h264only.user.js)
- [GitHub](https://raw.githubusercontent.com/paveloom-o/h264only/refs/heads/main/h264only.user.js)
- [GitLab](https://gitlab.com/paveloom-g/other/h264only/-/raw/main/h264only.user.js)
